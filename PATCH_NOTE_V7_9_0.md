# Patch note — V7.9.0

## À réviser

- La page **Résultats** affiche désormais un bloc **À réviser** lorsqu'il y a au moins une erreur.
- Les erreurs sont regroupées à partir des champs déjà présents dans les banques : matière, chapitre et `category`.
- Les thèmes avec le plus d'erreurs sont affichés en premier.
- **Réviser ce thème** relance toutes les questions disponibles de la catégorie concernée.
- **Réviser tout** crée une session regroupant toutes les catégories identifiées, sans dupliquer les questions.
- **Revoir mes erreurs** reste disponible pour reposer uniquement les questions ratées.
- Le mode de la session est conservé : QCM ou Vrai/Faux.
- Aucun changement des banques JSON existantes n'est requis.
- La fonctionnalité est disponible dans les versions web et locale.
