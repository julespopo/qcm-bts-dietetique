# Patch note — V7.8.3

Cette version ajoute un mode d'explications optionnelles au Vrai/Faux.

- Avant chaque nouvelle série Vrai/Faux, une popup demande si les explications doivent être affichées.
- Deux choix : **Avec explications** ou **Sans explications**.
- Si les explications sont activées, elles apparaissent après chaque réponse, y compris lorsqu'elle est correcte.
- Le panneau indique aussi si la proposition était vraie ou fausse.
- La progression attend une action sur **Question suivante** au lieu d'avancer automatiquement.
- Un bouton **Explications : activées / désactivées** reste disponible pendant la série.
- Désactiver les explications après une réponse referme le panneau et réactive l'avance automatique.
- La préférence est conservée lors d'une pause / reprise.
- La revue des erreurs continue à afficher systématiquement les explications.
- L'interface mobile conserve un bouton Suivant accessible lorsque le panneau d'explication est affiché.
